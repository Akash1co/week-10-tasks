# CIA Career Intelligence API Contract

**Implementation basis:** `routes/web.php`, `app/Http/Controllers/CiaController.php`,
and the invoked Python scripts as audited on 2026-11-17. All paths are relative
to the application origin. This reference distinguishes live controller-backed
workflows from route handlers that currently return fixed placeholder JSON.

## Conventions and middleware

- The CIA endpoints are registered in `routes/web.php`; the routes are in the
  Laravel `web` middleware group and all explicitly use `auth`.
- A request must have an authenticated application session/guard. A valid
  session cookie is the normal browser flow. `Authorization` is not a
  separately configured API-token contract in these route definitions.
- State-changing requests using cookie authentication must include the
  application's CSRF token (commonly `X-CSRF-TOKEN` or the framework's
  supported `X-XSRF-TOKEN` cookie/header flow).
- Send `Accept: application/json` to request JSON validation/authentication
  errors. Send `Content-Type: application/json` when sending a JSON body.
- `candidate_id` path values below are route parameters. The four live
  controller operations use the authenticated user's ID where applicable;
  they do not accept a client-selected candidate identity.
- The fixed examples for dashboard/profile/analytics routes reflect their
  current response bodies. They are placeholders, not database-backed
  response contracts.

### Common error response shapes

The controller's validation helper returns this exact `422` shape:

```json
{
  "status": "error",
  "message": "The provided data is invalid.",
  "errors": {
    "target_role": ["The target role field is required."]
  }
}
```

Controller-generated service errors use this shape; `log_id` is present only
when the failed workflow was successfully written to `cia_search_logs`:

```json
{
  "status": "error",
  "message": "Vector search could not be completed.",
  "log_id": 12
}
```

| Status | Meaning |
| --- | --- |
| `401 Unauthorized` | `auth` middleware rejected the request. The precise body/redirect is supplied by Laravel's configured guard and JSON negotiation; no CIA-specific `401` body is defined. |
| `419` | The web middleware rejected a missing/invalid CSRF token for a state-changing session request. |
| `422 Unprocessable Entity` | The four controller-backed POST actions return the explicit validation shape above. Placeholder closure handlers do not define field validation and do not generate this response themselves. |
| `500 Internal Server Error` | Controller-side JSON preparation failures use `{"status":"error","message":"..."}`. Uncaught database/framework exceptions use Laravel's global exception handler; this controller has no explicit `QueryException` catch or guaranteed CIA-specific response body. |
| `502 Bad Gateway` | A controller-backed Python/LLM service failed to start, exited unsuccessfully, returned invalid JSON, or returned an invalid result shape. Usually uses the controller-generated service error shape. Not generated by placeholder closures themselves. |
| `504 Gateway Timeout` | A controller-backed subprocess timed out. Uses the same service error shape. |

Error statuses are not all reachable from every route; applicability is noted
with each endpoint. The web framework may also produce its standard `404` and
other middleware errors.

## Route inventory

There are ten CIA route registrations in `routes/web.php`: four POST routes
backed by `CiaController` and six dashboard/profile/analytics closures.
`CiaController::searchHistory` exists but is not registered as a route.

handling. This closure does not define `422` or `502` behavior.

## 7. Analyze a candidate's skill gap

**Method/path:** `POST /candidate/cia/career/skill-gap`
**Route name:** `cia.career.skill_gap`

**Authentication:** `auth`; web session middleware and CSRF token for
cookie-authenticated requests. Candidate identity is derived from the
authenticated user.
**Implementation:** `CiaController::skillGap`.

### Request body

| Field | Type | Required | Validation/default |
| --- | --- | --- | --- |
| `target_role` | string | Yes | Maximum 120 characters. The controller trims it before matching the known role benchmarks. |

Example:

```json
{
  "target_role": "Full Stack Developer"
}
```

### `200 OK`

```json
{
  "score": 78,
  "gaps": ["Vector Search", "DevOps"],
  "priority_learning": [
    "Build Vector Search skills with focused practice aligned to the target-role benchmark."
  ],
  "radar_data": {
    "labels": ["Backend PHP", "Laravel", "Vector Search", "API Design", "DevOps"],
    "candidate_scores": [88, 92, 70, 85, 60],
    "target_scores": [88, 92, 75, 90, 75]
  }
}
```

Response schema:

| Field | Type |
| --- | --- |
| `score` | Integer readiness score from 0 through 100 |
| `gaps` | Array of strings |
| `priority_learning` | Array of strings |
| `radar_data.labels` | Five strings in fixed score order |
| `radar_data.candidate_scores` | Five numeric scores |
| `radar_data.target_scores` | Five numeric role benchmarks |

Known target benchmarks are configured for Backend Developer, Full Stack
Developer, Data Scientist, and DevOps Engineer; other roles use the default
benchmark. Completed lessons and completed quiz attempts are read for the
authenticated user. With provider keys configured, the controller sends the
skill profile and benchmark data to the fallback service; otherwise it returns
local benchmark-based suggestions.

### Errors

- `401`: authentication middleware; body follows Laravel behavior.
- `422`: invalid/missing `target_role`, with the common validation body.
- `500`: request serialization failure uses the controller error shape;
  database exceptions flow to Laravel's global handler.
- `502`: fallback process failure or invalid LLM response.
- `504`: subprocess/provider timeout.

## 8. Generate career recommendations

**Method/path:** `POST /candidate/cia/career/recommendations`
**Route name:** `cia.career.recommendations.generate`

**Authentication:** `auth`; web session middleware and CSRF token for
cookie-authenticated requests. `candidate_id` is derived from the user and
included in the internal workflow payload.
**Implementation:** `CiaController::careerRecommendations` invokes
`scripts/career_recommendations.py`.

### Request body

| Field | Type | Required | Validation/default |
| --- | --- | --- | --- |
| `target_role` | string | Yes | Maximum 120 characters; trimmed before use. |
| `skills` | Array of strings | No | At most 50 items; each at most 120 characters. Defaults to `[]`. |
| `skill_gaps` | Array of strings | No | At most 50 items; each at most 120 characters. Defaults to `[]`. |
| `profile` | JSON object / associative array | No | Must pass Laravel's `array` rule; defaults to `{}`. The Python consumer expects an object/dictionary. |

No non-empty constraint is imposed on `skills` or `skill_gaps`; blank strings
are not rejected by the controller's rules.

Example:

```json
{
  "target_role": "Backend Software Engineer",
  "skills": ["Python", "REST APIs"],
  "skill_gaps": ["PostgreSQL"],
  "profile": {
    "experience_level": "entry-level"
  }
}
```

### `200 OK`

```json
{
  "log_id": 18,
  "career_paths": [
    {
      "title": "API Platform Engineer",
      "overview": "Build a foundation in reliable backend services and API design.",
      "required_competencies": ["Python", "REST APIs", "PostgreSQL"],
      "milestones": [
        {
          "name": "Build an API",
          "action": "Deliver a tested service with documented endpoints.",
          "timeframe": "4 weeks"
        },
        {
          "name": "Add persistence",
          "action": "Model relational data and add migration coverage.",
          "timeframe": "3 weeks"
        },
        {
          "name": "Deploy and observe",
          "action": "Deploy the service and add health and error monitoring.",
          "timeframe": "2 weeks"
        }
      ],
      "estimated_timeframe": "9 weeks"
    }
  ]
}
```

`career_paths` contains exactly three objects. Each has a string `title`,
`overview`, and `estimated_timeframe`; a non-empty `required_competencies`
string array; and at least three `milestones`, each with string `name`,
`action`, and `timeframe`. The sample shows one of the three paths.
`log_id` is the integer key for the audit record in `cia_search_logs`.

### Errors

- `401`: authentication middleware.
- `422`: request validation failure.
- `500`: request JSON encoding failure; database exceptions use global Laravel
  handling.
- `502`: process start/failure, malformed JSON, or response that does not
  contain exactly three career paths.
- `504`: the 90-second subprocess timeout.

Service errors generally include `log_id` if writing the failed attempt to
`cia_search_logs` succeeded.

## 9. Generate an eight-week learning path

**Method/path:** `POST /candidate/cia/career/learning-path`
**Route name:** `cia.career.learning_path`

**Authentication:** `auth`; web session middleware and CSRF token for
cookie-authenticated requests. Candidate ID is used only for the audit log.
**Implementation:** `CiaController::learningPath` invokes
`scripts/langgraph_learning_path.py`.

### Request body

| Field | Type | Required | Validation/default |
| --- | --- | --- | --- |
| `target_role` | string | Yes | 1-120 characters and must contain a non-whitespace character. |
| `skills` | Array of strings | No | At most 50; each item required, at most 120 characters, non-whitespace. Defaults to `[]`. |
| `skill_gaps` | Array of strings | No | At most 50; each item required, at most 120 characters, non-whitespace. Defaults to `[]`. |
| `experience_level` | string | No | At most 80 characters. Defaults to `"intermediate"`. |
| `weekly_hours` | integer | No | 1-40 inclusive. Defaults to `7`. |
| `profile` | JSON object / associative array | No | Laravel permits an array up to 50 entries; the Python request model expects a dictionary. Defaults to `{}`. |

Example:

```json
{
  "target_role": "Full Stack Developer",
  "skills": ["PHP", "Laravel"],
  "skill_gaps": ["React", "Testing"],
  "experience_level": "intermediate",
  "weekly_hours": 7,
  "profile": {
    "completed_modules": ["REST APIs"]
  }
}
```

### `200 OK`

```json
{
  "log_id": 19,
  "title": "8-week learning path for Full Stack Developer",
  "summary": "A paced plan from role foundations to a portfolio-ready capstone.",
  "outcomes": ["Build readiness for the target role"],
  "schedule": [
    {
      "week": 1,
      "theme": "Role foundations and skill baseline",
      "days": [
        {
          "day": 1,
          "topic": "Role foundations: React - day 1",
          "practice": "Complete a focused React exercise and record one takeaway.",
          "estimated_hours": 1.0
        }
      ]
    }
  ],
  "mermaid": "gantt\n    title 8-week learning path",
  "validation": {
    "approved": true,
    "comments": ["Schedule shape and all 56 daily topics passed validation."]
  },
  "fallback_nodes": []
}
```

The example abbreviates schedule entries. The actual `schedule` has exactly
eight ordered weeks; every week has a `week` integer, `theme` string, and
exactly seven ordered `days`. Every day has a `day` integer, `topic` string,
`practice` string, and positive `estimated_hours` not exceeding 12. The
controller and Python service ensure the sum of daily estimated hours in a
week does not exceed `weekly_hours`. Top-level fields are `log_id` (integer),
`title` and `summary` (strings), `outcomes` (string array), `schedule`
(eight-week array), `mermaid` (string), `validation` (object with boolean
`approved` and string-array `comments`), and `fallback_nodes` (string array).

### Errors

- `401`: authentication middleware.
- `422`: invalid request fields.
- `500`: request JSON encoding failure; database exceptions use global Laravel
  handling.
- `502`: process failure, invalid JSON, or invalid schedule/response shape.
- `504`: the 240-second subprocess timeout.

Service errors generally include `log_id` if the failure record was saved.
The LangGraph service uses deterministic fallback output per failed model node
when Groq is unavailable; a structurally valid fallback plan can still return
`200 OK` with the affected node names in `fallback_nodes`.

## 10. Search roles by candidate skills

**Method/path:** `POST /candidate/cia/career/vector-search`
**Route name:** `cia.career.vector_search`

**Authentication:** `auth`; web session middleware and CSRF token for
cookie-authenticated requests. Candidate ID is derived from the authenticated
user for audit logging.
**Implementation:** `CiaController::vectorSearch` invokes
`scripts/vector_search_roles.py`, which queries `cynaris_career_roles`.

### Request body

| Field | Type | Required | Validation |
| --- | --- | --- | --- |
| `skills` | Array of strings | Yes | 1-50 entries; each entry is required, at most 120 characters, and must contain a non-whitespace character. Values are trimmed before the subprocess call. |

Example:

```json
{
  "skills": ["Python", "SQL", "Data Visualization"]
}
```

### `200 OK`

```json
{
  "log_id": 12,
  "matches": [
    {
      "role_id": "role-04",
      "role": "Data Analyst",
      "match_percentage": 84.2,
      "cosine_similarity": 0.842,
      "required_skills": ["SQL", "Excel", "Python", "Data Visualization", "Statistics"],
      "missing_skills": ["Excel", "Statistics"],
      "match_criteria": "Turn business data into reliable reports, dashboards, and actionable insights.",
      "metadata": {
        "category": "Data",
        "experience_level": "Entry-level",
        "work_mode": "Hybrid"
      }
    }
  ]
}
```

`matches` contains exactly five results. Each item has string `role_id`,
`role`, and `match_criteria`; numeric `match_percentage` (0-100) and
`cosine_similarity` (0-1); string arrays `required_skills` and
`missing_skills`; and a `metadata` object containing role category,
experience level, and work mode. `log_id` is the integer `cia_search_logs`
record key. Ranking uses cosine similarity computed from ChromaDB cosine
distance. The collection must be seeded with exactly 20 configured role
profiles before use.

### Errors

- `401`: authentication middleware.
- `422`: missing/empty `skills`, more than 50 skills, non-string entries, or
  blank/overlong skills.
- `500`: request JSON encoding failure; database exceptions use global Laravel
  handling.
- `502`: process start/failure, malformed output, or anything other than five
  matches.
- `504`: the 90-second subprocess timeout.

Service errors generally include `log_id` when the error record was stored.

## ChromaDB profile schema versus API availability

`docs/chromadb_schema.py` specifies a separate `cynaris_intern_profiles`
collection with metadata values `candidate_id` (string), `skills` (JSON
string), `scores` (JSON string), and `history` (JSON string), using cosine
distance. None of the ten route handlers in `routes/web.php` currently
retrieves or updates that collection. The live vector-search route queries
`cynaris_career_roles`, a different collection. See
[`architecture_cia_career_w12d2.md`](./architecture_cia_career_w12d2.md) for
the collection and integration details.

## Routes and methods not exposed

`CiaController::searchHistory` accepts an optional `target_role` string of at
most 120 characters and returns up to 50 newest records for the authenticated
candidate. It is not registered in `routes/web.php`; clients must not call it
as a supported endpoint until a route is added.
